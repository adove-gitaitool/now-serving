# Now Serving

A phone game for teaching observation bias in queues: when you walk into a one-server line, the customer being served tends to take longer than the average customer.

Play: open the site, enter a nickname and a room code. Instructors use **Instructor view** (or add `#host` to the link) to get a room code, a QR code and live class results.

Class results need a free Firebase Firestore database. Without one the game runs in solo mode.
